# ⚡ NITRO_ENGINE // BENCHMARK_CORE

A high-performance, lightweight hardware benchmarking utility designed in a minimalist brutalist cyberdeck aesthetic. This tool stress-tests browser compilation architectures by calculating the mathematical constant Pi (π) to maximum precision utilizing a parallelized asynchronous implementation of the infinite Leibniz infinite series expansion.

## 🛠️ Technical Architecture Matrix

- **Engine Foundations**: Vanilla HTML5, Semantic DOM architecture.
- **Layout Topology**: Pure CSS Grid & Flexbox framing models, zero heavy frameworks.
- **Computation Engine**: Asynchronous execution loops processing **20,000,000 algorithmic cycles** broken into managed memory windows to prevent browser main-thread blocking.
